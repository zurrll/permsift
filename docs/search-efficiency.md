# 减少权限搜索的运行次数

v0.3.1 优化候选调度，保持每次实际运行的干净副本、任务断言、前后边界检查、失败恢复和最终重复验证。

## 原来的成本

旧搜索每接受一次修改就从头尝试所有操作。clsx 的 v0.3.0 实验执行 190 个 trial，其中 105 次候选、76 次恢复，另外 9 次基线/准备确认/最终验证。撤销 dist 读取被试了 21 次，撤销构建脚本读取被试了 16 次。

权限变化可能改变程序分支，因此失败操作需要复查。但可以等一轮其他候选完成后再复查，不必每接受一个修改就重来。实际对比见 [validation.md](validation.md)。

## 同级授权成组撤销

同一个父路径下至少有 3 项待尝试授权时，先尝试一起撤销。读写搜索都支持；写搜索先使用输出缩小规则，读搜索先删除输入授权，再展开保留的目录。

组删除通过时一次接受全部修改。失败或 unknown 后，立即用之前的规则恢复复测；恢复通过才拆成两半继续实验。组失败不说明其中每一项都必要。恢复不通过就停止，不能继续依据这次比较收缩。

组操作保存在 source=group_removal 的 step 中，removed_grants 列出成员。每次实际尝试，包括拆分子组，都消耗同一个 max_candidates 预算；恢复不计入候选数。

成组尝试还可能发现两项授权可以共同撤销，即使分别撤销都会失败。仍然没有穷举所有组合：只按同级路径分组，少于 3 项时从单项开始，不证明全局最小解。多数授权都必要的小集合可能因失败分组增加少量成本。

## 按轮延后复查

一轮内，尝试过的操作不会因别处收缩而立即重试。新规则引入的子路径仍可在这一轮尝试；没有变化的旧操作继续往后排。

这一轮有接受修改时，再开始下一轮，重新尝试剩余操作。直到出现完整的无变化轮，或最后一次修改之后剩余候选已经全部实际比较过；预算耗尽、恢复不稳定也会停止。只有在当前组合下完成比较，才能省掉重复的收尾轮，不能将旧规则下的失败永久标记为必需。较早失败的复用线索不算这种实际比较。

步骤的 round 为从 1 开始的搜索轮次；每个场景的读、写轮次分别累计到 rounds。因写权限变化而再次执行读取搜索时，读取轮次继续累计。

## 相同失败组合只作为本轮线索

拆分时可能重现完全相同的候选：先删除一组失败，随后删除半组成功，再删除剩余半组，就回到了先前的失败组合。

只在同一次搜索、同一轮内，使用已经明确 fail 且恢复通过的相同候选授权组合作为排队和拆分线索。一次搜索内输入快照、准备状态、另一种权限和执行环境设置保持固定。unknown、恢复失败和 pass 都不作为失败线索；下一轮清空线索，避免省略后续复查。没有跨实验或跨环境缓存。

复用事件单独存放在 reuses，关联 failed_trial_id。它不生成新的 trial，不声称进行了一次新拒绝实验。Markdown 的 Reused failure hints 单独显示这些事件。只有新执行且通过的候选才被接受，最终策略仍从干净状态重复验证。

## 避免重复读写搜索

读权限变化后仍重新搜索写权限。如果写权限没有接受任何变化，已经完成的读取搜索不再原样重复。写权限发生变化时必须继续读取搜索，因为新的执行分支可能让其他输入变成可撤销项。真实测试包含这种读→写→读的情况。

## 同项目对比

准备固定提交的 clsx，正常验证会生成 summary.json：

```sh
npm run third-party:prepare
npm run third-party:verify
```

已有旧版本生成的 summary.json 时，可将它用于比较：

```sh
npm run third-party:verify -- --baseline .permsift/old-clsx/summary.json
```

old-clsx 是示意目录，要替换为保存的旧报告路径。没有旧报告时省略 --baseline。

工具运行新实验并重放推荐配置，生成 comparison.json。比较输入快照、场景配置、limits、系统/Node/SRT 版本和最终读写权限；不一致会保留对比文件并报错。比较要求两个搜索均 verified 且 search_complete=true。历史源码提交 ec9ee4a 对应 v0.3.0，可在独立副本中准备旧报告。

次数统计区分实际候选、恢复和总 trial，复用线索不算执行。一个 trial 是一次完整策略实验，包含任务及前后探针，不等于操作系统进程数；搜索总 trial 不包含另列的导出重放。duration_ms 包含搜索和 3 次导出重放；仅为本机单次观察，受后台负载及文件系统缓存影响，不是性能基准。实验仍可能达到预算，优化不保证所有项目都更快。
