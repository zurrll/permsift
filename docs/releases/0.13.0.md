# Permsift 0.13.0

这一版集中交付整体重构以来的能力：用真实任务建立、采用和复验权限规则；独立观察依赖，并用保存材料继续查询和比较。实验底座统一记录任务、约定、方案、执行证据和用户选择，任务成功、固定边界、保护目标与采集健康度分别判断。

## 两条使用路径

- 权限维护：explain 预览配置 → run 建立验证 → adopt 明确采用 → 代码/依赖变化后 check。需要较小规则时再用 tighten；当前恢复、候选与最终验证策略保持原行为。
- 依赖认知：explain 预览采集 → observe 执行原任务 → inspect --package 查询安装实例、加载与输入来源 → compare 只读比较保存记录。工具提供本次记录，不自动判定依赖可删除。

入口分别见 [权限维护入门](../getting-started-permissions.md) 与 [依赖观察入门](../getting-started-observation.md)；命令和配置以 [README](../../README.md) 为准。

## 本版的主要变化

1. 五对象底座与共同执行/保存流程完成；普通执行、收缩、复验和观察共用独立结果判断。
2. 配置静态解释、显式基线采用和约定变化审阅可用；采用保存历史证据，check 不自动替换基线。
3. 可选固定任务保护目标与最终产物保存；diagnose 离线检查声明的成功条件能拒绝哪些扰动。
4. 安装接入支持有明确归属的内嵌依赖，失败安装独立说明；增加显式退出码成功条件，原任务可直接接入。
5. 离线结果解释和包查询提供安装关系、Node 加载、TypeScript 输入与 esbuild 输入/贡献的独立记录。
6. Node 观察日志 v6 在原资源上限内分开加载与解析预算。已保存 XO 同输入实测记录从 325 增至 347 个包实例；辅助线程记录缺口继续保留，见 [实测](../load-and-resolution-budgets.md)。
7. 默认终端先显示有依据的答案，必要限定随结论保留，失败与证据问题突出显示；详细原因按需展开，见 [展示规则](../terminal-output.md)。
8. CI 保留代码的完整回归，简单取消过时运行并为纯文档变更省去 macOS 作业，见 [覆盖与收据](../ci-validation.md)。

## 安装与兼容

仍通过 Git 仓库克隆、npm ci --ignore-scripts、npm run build 使用；package 保持 private，没有发布 npm 包。Node 要求 >=22；执行沙箱任务要求 macOS，后端仍为 Anthropic Sandbox Runtime 0.0.77。配置解释和保存材料的离线入口可在支持的 Node 环境使用。

本版保留配置格式、现有原报告/summary JSON 和退出码；可选成功条件、保护目标、约定变化及产物保存的行为见各能力文档。check 新报告 wire v2、观察日志 v6 与工具版本 0.13.0 分别管理。新代码继续读取受支持的旧报告；不承诺旧工具能读取所有新日志或新字段。不同观察器版本的记录比较须考虑采集条件变化。

默认终端文本调整，不作为机器协议；--json 继续用于脚本。旧结果使用新 inspect 可得到新展示，无需迁移或重跑项目。

本轮展示验收复用已保存材料与明确标注的反例，核对完整通过、来源截断、任务/边界失败、缺失/损坏证据、约定变化和长列表。实际测试结果记录在 [开发说明](../development.md)。没有为展示验收新增 XO 执行、依赖安装或权限搜索；常规开发回归中的夹具执行另计。

4b11e47 的 [完整 CI](https://github.com/zurrll/permsift/actions/runs/37316285582) 已通过：Node 22/24 与 macOS 各 300 个单元/组件，83 个集成，以及 doctor、公共 CLI 和既有离线回放。版本号按本次完整交付集中整理；后续开发轮次不自动升版。
